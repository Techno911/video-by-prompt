# Видео по одному промту

[![selftest](https://github.com/Techno911/video-by-prompt/actions/workflows/test.yml/badge.svg)](https://github.com/Techno911/video-by-prompt/actions/workflows/test.yml)

Складываете исходники в папку, даёте нейросети одну ссылку и получаете готовый
Reels, Stories или другой короткий вертикальный ролик. Агент сам разбирает материал,
выбирает планы, строит драматургию, приводит HDR к нормальному цвету, делает монтаж,
титры, звук и техническую приёмку.

Это не генератор видео. Он монтирует ваши настоящие фотографии и видео локально,
на вашем компьютере. Исходники никуда не отправляются самим инструментом.

## Как пользоваться

Нужен агент, который видит файлы и умеет выполнять команды: Codex, Claude Code или
другой coding agent с терминалом.

1. Сложите видео и фотографии в одну папку.
2. Откройте агента в этой папке.
3. Отправьте одно сообщение:

```text
https://github.com/Techno911/video-by-prompt

Прочитай инструкцию по ссылке. Смонтируй из материалов в этой папке готовый Reels.
Все творческие решения принимай сам. Отдай финальный MP4 и контактный лист.
```

Всё. Если важны длина, формат или настроение, добавьте это одной строкой. Например:

```text
Нужно 20 секунд, тепло и живо, без разговорных титров.
```

Обычный чат Claude или ChatGPT без доступа к компьютеру сможет придумать сценарий,
но не сможет честно отрендерить файл. Для пути целиком нужен именно агент с терминалом.

## Что происходит внутри

1. Агент проверяет Python, ffmpeg и возможности компьютера.
2. Снимает инвентарь исходников: дата, длина, размер, HDR, поворот и звук.
3. Делает контактные листы, чтобы выбирать планы глазами, а не по именам файлов.
4. Собирает покадровый `storyboard.json`.
5. Рендерит каждый план в точной сетке кадров.
6. Накладывает титры только внутри безопасной зоны интерфейса соцсети.
7. Нормализует звук в два прохода по EBU R128.
8. Проверяет мастер полным декодом: CFR, число кадров, BT.709, AAC, громкость,
   пики, чёрные отрезки, зависшие кадры и тишину.
9. Показывает контактный лист и исправляет монтаж, если история не читается.

Новый мастер появляется под финальным именем только после всей приёмки. Неудачная
сборка не перезаписывает предыдущий результат.

## Что умеет движок

- вертикальные и горизонтальные видео, фотографии;
- iPhone HEVC, 10-bit HLG/PQ HDR и rotation metadata;
- аппаратный HDR в BT.709 через `scale_vt` на Apple;
- переносимый fallback через `zscale + tonemap`;
- точный CFR и хронометраж до кадра;
- 9:16 по умолчанию, другие размеры и fps через JSON;
- декларативные титры и проверка safe zone;
- один финальный H.264 encode без цепочки повторных пережатий;
- двухпроходный loudness и атомарная сдача;
- синтетический сквозной самотест без ваших материалов.

## Самостоятельный запуск

Если хочется запустить руками:

```bash
git clone https://github.com/Techno911/video-by-prompt.git
cd video-by-prompt
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
cp storyboard.example.json storyboard.json
```

В `storyboard.json` укажите папку с исходниками и планы, затем:

```bash
./.venv/bin/python storis.py --check
./.venv/bin/python storis.py
```

На Windows команды окружения выглядят так:

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy storyboard.example.json storyboard.json
.venv\Scripts\python storis.py --check
.venv\Scripts\python storis.py
```

Нужен Python 3.10 или новее и ffmpeg с `libx264`. На macOS:

```bash
brew install python ffmpeg
```

На Ubuntu:

```bash
sudo apt install python3 python3-venv ffmpeg
```

## Проверка установки

```bash
./.venv/bin/python selftest.py
```

Самотест сам создаёт движущиеся тестовые видео и звук, собирает короткий мастер,
прогоняет всю приёмку и удаляет временные исходники после успеха.

## Для нейросети

Если вы агент и человек прислал вам эту ссылку, прочитайте
[AGENT_PROTOCOL.md](AGENT_PROTOCOL.md) целиком. Там обязательный порядок от папки
с исходниками до принятого мастера. Не перекладывайте технические решения на человека
и не объявляйте работу законченной, пока не увидели реальный ролик и результаты QA.

## Приватность

- `media/`, `out/`, `cache/` и пользовательский `storyboard.json` исключены из git.
- Исходники не удаляются и не переносятся.
- Инструмент не содержит загрузки в облако и внешних API.
- Музыку он не скачивает. Используйте живой звук или файл, на который у вас есть права.
