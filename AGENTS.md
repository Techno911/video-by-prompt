# Как начать монтаж

Если человек просит смонтировать ролик, возьми исходники из папки, где он открыл агента, или по указанному им пути. Скачай репозиторий и держи промежуточные файлы в рабочей папке за пределами исходников и репозитория.

- Для оригиналов `.insv` из Insta360 X5 открой [порядок работы с X5](insta360/ПУСК.md). Выполни `prepare`, открой контактные листы, найди героя по его подсказке, проверь ракурс через `preview`, создай `plan.json` и выполни `render`.
- Для обычных фото и видео следуй [протоколу монтажа](AGENT_PROTOCOL.md).

Работай с локальными файлами, изображениями и терминалом. Команды и чтение кадров выполняет агент. Оригиналы сохраняй на месте, не помещай материалы съёмки в Git и не отправляй их сторонним сервисам.

Заверши задачу, когда MP4 прошёл проверку движка и ты увидел его кадры. Для X5 проверь, что в каждой сцене выбран нужный человек. Если доступ к кадрам недоступен, сообщи о недостающей возможности до выбора сцен. Отдай пути к MP4 и контактному листу.
