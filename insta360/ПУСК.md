# Вертикальный ролик из Insta360 X5

Из оригиналов `.insv` агент соберёт вертикальный ролик с нужным человеком. Подойдёт Codex, Claude Code, Kimi Code или другой агент, которому доступны локальные файлы, просмотр кадров и терминал. Сборка X5 работает на Mac с Apple Silicon и Python 3. Если FFmpeg ещё отсутствует, нужен настроенный Homebrew. Агент сам скачивает утилиту склейки, проверяет её SHA-256, при необходимости устанавливает FFmpeg и создаёт локальное Python-окружение для монтажа.

Положите оригиналы .insv в одну папку и откройте агента в ней. Дайте ему этот текст:

```
Скачай https://github.com/Techno911/video-by-prompt и прочитай insta360/ПУСК.md. Сделай вертикальный ролик со мной из файлов Insta360 X5 в этой папке. Ищи меня по экипировке: [цвет куртки, рюкзак, лыжи]. Проверь, что в готовом ролике главный герой я. Отдай MP4 и контактный лист.
```

## Маршрут агента

1. Скачай репозиторий в отдельную папку и выполняй команды из его корня. Запусти `python3 insta360/run.py prepare <папка-с-INSV> <рабочая-папка>`. Программа берёт оригиналы без LRV, проверяет возможность склейки и создаёт панорамы 2:1. Оригиналы остаются на месте.
2. Прочитай `sources.json` и контактные листы `frames-NNN`. На каждом листе до 16 кадров слева направо и сверху вниз, шаг около секунды. Второй лист начинается примерно с 16-й секунды. Сопоставляй несколько признаков героя и прослеживай его движение между соседними кадрами. Для близких экипировок и перекрытий смотри более частые кадры из `pano-NNN.mp4`. При необходимости увеличь фрагмент, чтобы сверить предметы экипировки. Главный критерий здесь принадлежность проезда человеку.
3. Выбери короткие выразительные проезды. Для входа, середины и выхода проверь ракурс командой `python3 insta360/run.py preview <рабочая-папка> <номер-источника> <секунда> <x> <y>`. Координаты `x` и `y` задают центр героя в полной панораме долями от ширины и высоты, от верхнего левого угла. Команда вернёт путь к вертикальному JPG и углы `yaw`, `pitch`. Открой JPG, при необходимости поправь координаты и только затем перенеси углы в `plan.json`. В каждом ключе первая величина это время относительно начала сцены. Разметка работает на 30 кадрах/с.
4. Запусти `python3 insta360/run.py render <рабочая-папка> <plan.json>`. Скрипт рефреймит выбранные сцены и передаёт их в штатный движок. Звук берётся из исходной панорамы. После монтажа полностью просмотри результат и контактный лист. Смотри, не потерялся ли герой на входе, выходе и в переходе между линзами. Исправь ключи или границы конкретной сцены и проверь снова.
5. Отдай `result/reel.mp4` и `result/reel_contact.jpg` после этой проверки. Сохрани план рядом с результатом. При похожей экипировке сначала проверь соседние секунды и склейку, затем при реальной неоднозначности запроси один ориентир.

```json
{
  "scenes": [
    {
      "source": 1,
      "start": 12.5,
      "frames": 90,
      "keys": [[0, 40, -4], [1.5, 52, -1], [3, 66, 3]]
    }
  ]
}
```

Пример задаёт окно и траекторию, а на новой съёмке координаты и время агент определяет по вашим кадрам. Конечный файл принимается после визуальной проверки и технического прогона движка. Команда сама проделывает технические шаги, а человек сообщает, кого искать.
